# Installation

Clone the repo and install:

```bash
git clone https://github.com/sirkostya009/kit-docs
cd kit-docs
pnpm install
```

## Requirements

- Node 20+
- pnpm 10+

## Dev server

```bash
pnpm dev
```

Open <http://localhost:5173>.

## Building

```bash
pnpm build
```

Output lands in `build/` ready to ship to any static host.
